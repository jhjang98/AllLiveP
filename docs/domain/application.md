# 도메인: 지원 (application)

> 상태: 초안 v0.1 (2026-09-28) — 사용자 확인 전
> 레거시 대응: `applicant` + `applicant_log`. 레거시는 콜센터 상담 → "연계" 중심의 복잡한 코드표 상태였으나, 신규는 기관이 직접 지원자를 열람하므로 **콜센터·연계 단계를 제거하고 단순화**한다.

## 용어

| 용어 | 정의 |
|---|---|
| 지원 | 일반회원이 특정 공고에 참여 의사를 접수하는 행위. 회원 전용 |
| 열람 | 기관회원이 지원자의 개인정보를 확인하는 행위. 기록이 남는다 |
| 선정/미선정 | 기관회원이 지원자를 검토한 결과 |

## 상태 (제안 — 확정 필요)

| 상태 | 설명 | 변경 주체 |
|---|---|---|
| applied | 지원 완료 (기관 미열람) | 시스템 |
| viewed | 기관이 열람함 | 시스템(첫 열람 시 자동) |
| in_progress | 기관이 연락·검토 진행 중 | 기관회원 |
| selected | 선정 (시험 참여 확정) | 기관회원 |
| not_selected | 미선정 (사유 선택) | 기관회원 |
| canceled | 지원자 본인 취소 | 일반회원 |

- 레거시의 대분류 9종 + 세부코드 체계는 콜센터 운영용이므로 승계하지 않는다. 위 6종으로 시작하고, 운영하며 세분화한다.
- 레거시의 "관리자 승인 후 기관 노출"(approved_yn) 단계는 신규에서 **제거를 제안** — 공고 자체를 검수하므로 지원 건별 승인은 이중 절차. [확정 필요]

## 상태전이

```
applied ──첫 열람──▶ viewed ──▶ in_progress ──▶ selected | not_selected
   │                   │              │
   └────────── canceled (지원자 취소: selected 전까지 가능) ──────┘
```

## 계산·판정 규칙

- R-P01 지원 자격: 로그인 + 프로필의 성별·생년월일이 공고 모집조건 부합
- R-P02 중복 차단: 동일 회원 × 동일 공고 1건 (canceled 후 재지원 허용 여부 [확정 필요], 레거시는 취소 건 재지원 불가 그룹 처리)
- R-P03 1일 지원 한도: 레거시는 1일 1회 — 신규 유지 여부 [확정 필요]
- R-P04 열람 차단: 공고 열람기한 경과 시 기관회원의 지원자 개인정보 열람 차단 (목록의 비식별 통계는 허용)

## 권한

| 행위 | 지원자 본인 | 해당 공고의 기관회원 | 타 기관회원 | 관리자 |
|---|---|---|---|---|
| 지원 내역 조회 | O (자기 것) | O (자기 공고 지원자만) | X | O |
| 개인정보 열람 | O | O (열람 기록 남김) | X | O (기록 남김) |
| 상태 변경 | 취소만 | in_progress/selected/not_selected | X | 전체 |

- RLS 원칙: 기관회원은 `자기 기관의 공고에 달린 지원`만 접근 가능

## 제약·정책

- 지원 시 수집 항목: 회원 프로필(이름·연락처·성별·생년월일) + 거주지역 + 동의 (개인정보 수집 필수, 제3자(기관) 제공 필수, 민감정보 수집·제공은 공고 설정에 따라)
- 모든 상태 변경과 개인정보 열람은 이력 테이블에 기록 (누가·언제·무엇을·IP)
- 지원자 개인정보의 엑셀 다운로드: 제공 여부 [확정 필요]. 제공 시 사유 입력 + 로그 (레거시 정책 승계)
- 상태 변경 시 지원자 알림 발송 (채널은 열린 질문 — 알림톡/SMS/이메일)

## 오류 케이스

- E-P01 모집조건(성별/나이) 불일치 → 지원 버튼 비활성 + 사유 표기
- E-P02 중복 지원 → 거부, 기존 지원 내역으로 안내
- E-P03 마감 공고 지원 → 거부
- E-P04 열람기한 경과 후 열람 시도 → 차단, "열람 기간이 종료되었습니다"
- E-P05 selected 상태에서 지원자 취소 시도 → 차단, 기관 문의 안내 [확정 필요]

## 확정 및 기본값

1. 지원 건별 관리자 승인 단계: **제거** (기본값 채택 — 공고 검수로 대체)
2. 취소 후 재지원: 불가, 1일 1회 지원 한도: 유지 (기본값 채택 — 레거시 정책 승계)
3. 엑셀 다운로드: 1차 범위 제외 (기본값 채택 — 도입 시 사유 입력 + 로그 필수)
4. not_selected 사유 코드: 관리자 코드 관리 화면에서 운영 중 정의 (기본값 채택)
5. 알림 채널: **이메일** (사용자 확정 2026-09-28)
