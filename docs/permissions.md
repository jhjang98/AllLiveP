## 원칙

1. 개인정보가 걸린 행위는 전부 S — 서버에서 검증·기록 후 수행. RLS는 2차 방어선
2. `application_events`(열람·상태 이력)는 누구도 수정·삭제 불가 (관리자 포함, append-only)
3. 관리자 권한은 1차 버전에서 단일 등급. 세분화(검수자/운영자 구분)는 운영 후 결정
4. 기관회원의 지원자 접근 범위 = 자기 기관 공고 × 열람기한 내
