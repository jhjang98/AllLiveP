## 범위 제외 (레거시에 있었으나 신규 1차 제외)

- 콜센터 상담·콜스크립트(설문) 관리, 유입경로별 오프라인 이미지, Meta 광고 리포트·웹훅, 의뢰사 대시보드, 앱 API, 이벤트/리뷰(레거시 사장 기능), 결제 기능(등록 무료 정책)

## 화면 공통 규칙

- 모든 화면은 반응형(모바일 웹 우선)
- 각 화면은 빈/로딩/오류/성공 4가지 상태를 정의한다 (③ 화면설계에서)
